# 2. iOS app architecture

## Status

Accepted

## Context

The iOS app must be easy for agents to extend safely, with a design system that can change at any time, a REST layer to be implemented later, feature flags, and full test coverage.

## Decision

- SwiftUI and Observation, iOS 17+. Project generated by XcodeGen from `project.yml`.
- MVVM with a composition root (`AppContainer`), a `Router` for navigation and protocol-based services.
- All styling through `Theme` tokens and `DS*` components.
- `APIClient` protocol with a URLSession client for real backends and a fixture client for tests.
- Feature flags resolved as: launch argument or device override, then backend, then default.
- Unit tests (XCTest), UI tests (XCUITest) and end-to-end tests (Maestro), all run in CI on every pull request.

## Consequences

- New features follow one checklist (see `apps/ios/.agents/skills/ios-architecture`).
- Tests never need a running backend.
