# iOS app

Native iOS app (AgenticApp) (Swift, SwiftUI, iOS 17+). Project is generated by XcodeGen from `project.yml`.

## Skills

- Follow the root `AGENTS.md` first. Shared skills in the root `.agents/skills/` are used for refinement, planning, defining tasks and code review.
- iOS skills live in `apps/ios/.agents/skills/`:
  - `ios-architecture` – layers, where code goes, new-feature checklist
  - `ios-design-system` – Theme tokens and DS components
  - `ios-rest-api` – endpoints, repositories, fixtures
  - `ios-feature-flags` – switching features on and off
  - `ios-testing` – unit, UI and end-to-end tests
  - Community skills: `swiftui-expert`, `swift-concurrency`, `swift-testing-expert` (MIT). Our `ios-*` skills take priority.

## Commands

Run from `apps/ios`: `make generate`, `make lint`, `make typos`, `make test-unit`, `make test-ui`, `make e2e`, `make ci`.

## Environments

`Dev`, `Syst` (SYST), `Prod` build configurations (`Config/*.xcconfig`). Tests run in `Syst`. Never point local work at `Prod`.

## Definition of done

- `make ci` passes locally and all pull request checks are green.
- New logic has unit tests, new screens have a UI test, new journeys have a Maestro flow.
- New or unfinished features are behind a feature flag.
