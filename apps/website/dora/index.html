Delivery performance

How fast and how safely changes reach customers, measured from this repository every week. The four keys come from Google's DevOps Research and Assessment (DORA) programme.

The four keys

How it is measured

  • Deployment frequency: how often a change reaches production. Until every app deploys automatically, each pull request merged into main counts.
  • Lead time for changes: median time from a pull request's first commit to its merge.
  • Change failure rate: issues labelled incident plus reverted changes, divided by deployments.
  • Time to restore service: median time from opening an incident issue to closing it.

The DORA metrics workflow updates the numbers every Monday. See ADR-0010 for the reasoning.
