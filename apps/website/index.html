Built for

What is ready today, and what you add on top for your business model.

Consumer products (B2C)

Ready today: sign up and sign in, profiles, iOS, Android and web apps, a back office for support, feature flags and Dev, SYST and Prod.

You add: your product's features, and payments if you need them.

Business products (B2B)

Ready today: accounts, an admin back office, security scanning and quality gates.

You add: organisations and teams, invites, roles and permissions, single sign-on (for example Entra ID), separate data per company and billing.

Partner platforms (B2B2C)

Ready today: the same foundation as B2B.

You add: everything for B2B, plus a partner layer: each partner's own branding, customers and data.

Good fits: mobile-first apps, SaaS web apps, customer portals with an admin back office, and internal tools. Not included yet: payments, organisations, single sign-on and multi-tenancy.

How it works

  1. Shape the idea and settle the open questions.
  2. Refine the language and record decisions.
  3. Specify the feature as an issue.
  4. Plan it as small tickets an agent can pick up.
  5. Build each ticket test-first, on any platform.
  6. Review the pull request; all checks must pass.
  7. Learn with a retro and improve the setup.

Quality built in

  • Lint and spell check
  • Unit tests with a coverage minimum
  • UI tests
  • End-to-end tests against the real backend
  • Feature flags for safe releases
  • Dev, SYST and Prod environments
  • Crash reporting and dashboards for every app
  • Delivery performance tracked with DORA metrics
