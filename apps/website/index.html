What's inside

iOS app

SwiftUI with sign up, sign in, profile, navigation, feature flags and push notification setup.

Web app

React and TypeScript with the same account flow as the mobile app.

Back office

For support and admins: find, edit, disable and delete customers, and switch features on or off.

.NET backend

Accounts, profiles, admin and feature flag APIs, with Dev, SYST and Prod environments.

Design system

One colour palette and set of tokens, generated for every app and ready for Figma.

Agent skills

Shared skills for the whole lifecycle, plus platform skills for each app.

How it works

  1. Shape the idea and settle the open questions.
  2. Refine the language and record decisions.
  3. Specify the feature as an issue.
  4. Plan it as small tickets an agent can pick up.
  5. Build each ticket test-first, on any platform.
  6. Review the pull request; all checks must pass.
  7. Learn with a retro and improve the setup.

Quality built in

  • Lint and spell check
  • Unit tests with a coverage minimum
  • UI tests
  • End-to-end tests against the real backend
  • Feature flags for safe releases
  • Dev, SYST and Prod environments
