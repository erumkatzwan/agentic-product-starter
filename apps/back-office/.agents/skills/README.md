# Back office skills

| Skill | Use it when |
|---|---|
| `web-architecture` | Adding a page, API call, feature flag or component |
| `web-testing` | Writing unit or end-to-end tests, or fixing a red check |

Shared skills (spec, tickets, implement, tdd, code review, retro) live in the root `.agents/skills/`. The web app and back office follow the same conventions.
